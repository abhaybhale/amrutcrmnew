# Deploying crmnew.amrutsoftware.in on Google Free Tier

This project is configured to run on Firebase **Spark/free-compatible**
services only:

- Firebase Hosting
- Firebase Authentication, Email/Password
- Cloud Firestore

Cloud Functions have deliberately been removed from `firebase.json` because
Functions require the Blaze billing plan. AI proxy, server-side demo
provisioning, and background sync can be added later, but they are not part
of this no-additional-charges deployment.

## 1. Google/Firebase Console Setup

1. Open [Firebase Console](https://console.firebase.google.com/).
2. Use the existing project in `.firebaserc`, or create/select your own
   Firebase project and update `.firebaserc`.
3. Go to **Build > Authentication > Sign-in method** and enable
   **Email/Password**.
4. Go to **Build > Firestore Database** and create the default database in
   production mode.
5. Stay on the Spark/free plan. Do not enable Cloud Functions for this build.

## 2. App Configuration

The project is already configured with:

```json
{
  "projects": {
    "default": "gen-lang-client-0722379473"
  }
}
```

If you create a different Firebase project, replace that id in `.firebaserc`
and paste the Firebase web-app config into `firebase-applet-config.json`.

`.env.local` is configured for:

```bash
APP_URL="https://crmnew.amrutsoftware.in"
VITE_AI_FUNCTION_URL=""
VITE_ACTIVATE_USER_FUNCTION_URL=""
VITE_PROVISION_DEMO_FUNCTION_URL=""
```

Leaving the function URLs blank is intentional for free-tier deployment.

## 3. Build And Deploy

From this folder:

```bash
npm install
npm run build
firebase login
firebase deploy --only firestore:rules,hosting
```

Because `firebase.json` no longer contains a Functions section, `firebase
deploy` will not try to deploy Cloud Functions.

## 4. Custom Domain

In Firebase Console:

1. Go to **Hosting > Add custom domain**.
2. Enter `crmnew.amrutsoftware.in`.
3. Add the TXT verification record at your DNS provider.
4. After verification, add the A records Firebase shows.
5. Wait for SSL certificate status to become connected.

## 5. First Login

1. Open `https://crmnew.amrutsoftware.in`.
2. Sign in with an account provisioned in Firebase Authentication.
3. For an invited user, use the unique activation code generated by an
   administrator. There is no universal activation code.

Database seeding is disabled in production. Set
`VITE_ALLOW_DATABASE_SEEDING=true` only for a controlled one-time
initialization, then rebuild immediately with it set back to `false`.

## Notes

- Sign in as Abhay first on a clean Firestore database so the initial CRM
  data can seed with admin permission.
- Do not deploy `functions` unless you are ready to enable Blaze billing.
- Gmail/Calendar sync needs a Google OAuth client and API enablement, but no
  Cloud Functions.
